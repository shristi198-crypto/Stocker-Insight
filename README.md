# 📈 Stocker Insight

Stocker Insight is a modern stock market analytics platform built to help investors make informed decisions using real-time market data, technical indicators, historical analysis, and AI-powered insights.

## 🚀 Features

- 📊 Live Stock Market Data
- 📈 Interactive Charts
- 🔍 Stock Search
- 💹 Technical Indicators
- 📰 Latest Market News
- 📉 Historical Price Analysis
- ⭐ Watchlist Management
- 🔥 NSE Top Gainers & Losers
- 📊 Sector-wise Market Performance
- 🤖 AI-based Stock Insights
- 📱 Responsive User Interface

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- ShadCN UI

### Backend
- Node.js
- Express.js

### APIs
- Yahoo Finance
- NSE Market Data

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/stocker-insight.git
```

Move into the project folder

```bash
cd stocker-insight
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

The application will run on

```
http://localhost:5000
```
